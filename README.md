# Big Bite Restaurant Website

A responsive Next.js 15 + React + TypeScript website for Big Bite, Rawalpindi.

## Run locally

1. Install Node.js 20.9 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.
4. Run `npm run build` before deployment.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository at https://vercel.com/new.
3. Keep the framework preset as Next.js and the build command as `next build`.
4. Deploy. No environment variables are required.

## Content and verification notes

- WhatsApp order enquiries use +92 336 5583333. The site does not represent an enquiry as a confirmed order.
- Phone numbers, address, supplied opening hours, rating and review count are based on information provided for this project.
- Individual pizza names/prices were not legible in the supplied printed menu photos, so the site points visitors to the supplied pizza combo deals or WhatsApp for the current pizza menu.
- Loaded Fries, Pizza Fries and several pasta items show two prices without verified size labels. The site preserves both prices and flags the missing size detail.
- Wings/nuggets prices are shown as two values; the supplied image appears to indicate 5-piece / 10-piece columns, but the headings need restaurant confirmation.
- Friday's supplied hours (12:00 AM–1:00 PM) are shown with a verification note because they appear unusual.
- Review text is based on supplied summaries, not represented as exact verbatim Google quotations.
- Add the final deployed domain to metadata/Open Graph configuration before launch if absolute social-preview URLs are required.
- Google rating/review count and business details should be rechecked before public launch.
